# Kohakuyasha

Kohakuyasha — переносимая локальная система-помощница для Windows с русским веб-интерфейсом, SQLite, системным треем, watchdog, автозапуском и встроенной диагностикой.

## Быстрый запуск

1. Скопируйте папку проекта на обычный диск, внешний SSD или флешку.
2. Дважды щёлкните `Kohakuyasha.bat`.
3. Если подходящего системного Python 3.11+ нет, bootstrap скачает закреплённый переносимый Python из версии `PYTHON_VERSION` с python.org в `.runtime/`.
4. Runtime-зависимости из `requirements.lock` устанавливаются автоматически только при изменении lock-файла или интерпретатора.
5. Откроется локальная панель, а Kohakuyasha останется в области уведомлений Windows.

Веб-интерфейс слушает только `127.0.0.1`. Localhost сам по себе не считается защитой: v0.11.1 дополнительно проверяет `Host`, `Origin`, локальную session-cookie и WebSocket origin/session.

## Возможности v0.11.1

- **Диск Kohakuyasha** (пункт меню): личное файловое хранилище в `data/disk/files` — папки и хлебные крошки, загрузка перетаскиванием с прогрессом (файлы пишутся на диск потоком, лимит одного файла настраивается), сетка/список, предпросмотр картинок, текста, аудио и видео, PDF в новой вкладке, скачивание, переименование, перемещение, поиск, корзина с восстановлением (автоочистка через 30 дней). Пути строго ограничены папкой диска; HTML/SVG никогда не открываются в браузере, только скачиваются.

- **Уведомления на аватаре:** значок со счётчиком и подсказка над аватаром; нажатие открывает чат, где карточка сообщает о событии и даёт кнопки. Например, «Доступно обновление v… — Установить / Подробнее / Позже», после установки — «Перезапустить сейчас». Сервер сам проверяет GitHub в фоне (раз в 6 часов, если включена автопроверка) и показывает системное уведомление Windows из трея. Выключается в Настройках → Уведомления.

## Тесты разработчика

Тесты не устанавливаются и не запускаются при обычном старте. Для полного developer-suite используйте:

```bat
scripts\run_tests.bat
```

Скрипт создаёт отдельное `.runtime\dev-venv` и использует `requirements-dev.lock`.

В веб-интерфейсе кнопки «Быстрый тест» и «Полная диагностика» запускают только встроенную диагностику приложения.

## Диагностика запущенного экземпляра

```bat
scripts\diagnose.bat
```

Скрипт читает фактический порт из `data\runtime.json`, проверяет PID/TCP и открывает раздел тестов только для живого экземпляра.

## Source of truth

Этот репозиторий — единственный источник истины проекта. Текущее состояние находится в `PROJECT_STATE.json`, очередь задач — в `TASKS.json`, история — в `CHANGELOG.jsonl` и `ERRORS.jsonl`, архитектурные решения — в `DECISIONS.md`. Текущая версия проекта хранится только в `VERSION`.
## Интерфейс
- **Обзор**: только состояние системы.
- **Обновление**: проверка и установка новой версии проекта прямо из GitHub (с резервной копией и откатом), см. ниже.
- **Настройки**: тема (тёмная, чёрная, белая, как в системе), цвет акцента, фон (свечение, однотонный, своё изображение), масштаб, узор, лепестки и анимации, автозапуск, экспорт данных.

## Аватар, чат и личный кабинет
- Аватар доступен на любой странице. Перетаскивается куда угодно; можно загрузить своё лицо, подобрать кадр и применить его везде. Настраиваются форма, размер, прозрачность, рамка, свечение, анимация, прилипание к краю, приглушение, приветствие и действия левого/правого клика.
- **Левый клик** — чат в стиле ChatGPT (Markdown, код с копированием, подсказки, новый чат).
- **Правый клик** (на сенсорном экране — долгое нажатие) — личный кабинет: профиль, аватар, ИИ, память, система. Окна чата и кабинета можно двигать за заголовок и менять размер за любой край или угол.
- **ИИ**: только Cloud.ru (Evolution Foundation Models): DeepSeek V4 Flash и V4 Pro или любая другая модель по id. API-ключ хранится только в `data/secrets.json` и никогда не показывается обратно.
- **Память**: вставьте или загрузите диалоги (экспорт ChatGPT/Claude, JSON, JSONL, текст) и заметки; подходящие фрагменты подставляются в запрос. Это не дообучение модели, а локальная долговременная память.

## Оформление
Мягкий «лисий» стиль: узор «волны» (сэйгайха), светящиеся хвосты на фоне, лепестки сакуры, классические заголовки. Узор, лепестки и анимации отключаются в настройках; темы: тёмная, чёрная, белая, как в системе. В чате есть кнопка «Остановить», разделители по дням и крупный аватар.

## Логика ассистента
- **Факты о вас**: Kohakuyasha сама выделяет устойчивые факты из разговоров (раз в несколько сообщений) и мгновенно запоминает по команде «Запомни: …». Факты можно править, закреплять, оценивать по важности и удалять во вкладке «Память».
- **Краткое содержание**: старая часть беседы сжимается в несколько предложений, чтобы ассистент помнил ход разговора.
- **Brain v4**: сложные задачи получают внутренний многошаговый planner и проверку уверенности; короткие команды «продолжай/делай дальше» продолжают последнее состояние задачи, а новая противоположная информация заменяет устаревшие автоматические факты.
- **Время и календарь**: ассистент знает дату, время и ваши заметки на сегодня и ближайшие дни.
- Всё хранится локально; в Cloud.ru уходят только запросы к модели.

## Обновление проекта
Меню «Обновление» сравнивает установленную версию с файлом `VERSION` в репозитории GitHub, показывает «Что нового» и устанавливает обновление одним нажатием. Ваши данные (`data/`, `logs/`, ключи, память) не затрагиваются; перед заменой файлов создаётся резервная копия (хранятся последние 3), доступен откат. После установки нужен перезапуск (в Windows кнопка «Перезапустить сейчас»). Для приватного репозитория укажите токен GitHub только на чтение (Contents: Read-only). Автопроверка лишь показывает значок у пункта меню и ничего не устанавливает сама.
