# Kohakuyasha

Kohakuyasha — переносимая локальная система-помощница для Windows с русским веб-интерфейсом, SQLite, системным треем, watchdog, автозапуском и встроенной диагностикой.

## Быстрый запуск

1. Скопируйте папку проекта на обычный диск, внешний SSD или флешку.
2. Дважды щёлкните `Kohakuyasha.bat`.
3. Если подходящего системного Python 3.11+ нет, bootstrap скачает закреплённый переносимый Python из версии `PYTHON_VERSION` с python.org в `.runtime/`.
4. Runtime-зависимости из `requirements.lock` устанавливаются автоматически только при изменении lock-файла или интерпретатора.
5. Откроется локальная панель, а Kohakuyasha останется в области уведомлений Windows.

Веб-интерфейс слушает только `127.0.0.1`. Localhost сам по себе не считается защитой: v0.5.0 дополнительно проверяет `Host`, `Origin`, локальную session-cookie и WebSocket origin/session.

## Возможности v0.5.0

- переносимый запуск с любого носителя;
- закреплённый portable Python без выбора alpha/beta/rc;
- dependency state, привязанный к конкретному интерпретатору;
- отдельные runtime и dev/test зависимости;
- точно закреплённые версии зависимостей;
- защита от нескольких экземпляров и проверка stale `runtime.json`;
- SQLite с WAL, health-check, проверенными backup/recovery и ротацией копий;
- защищённый localhost HTTP API и WebSocket;
- System Tray с неблокирующими действиями;
- watchdog с backoff и повторным выбором порта при restart;
- русский бело-золотой веб-интерфейс и live-телеметрия;
- быстрые/полные диагностические проверки;
- переносимый автозапуск с локальным instance ID и поддержкой путей с кириллицей;
- safe mode, экспорт диагностики и ротация логов.

## Тесты разработчика

Тесты не устанавливаются и не запускаются при обычном старте. Для полного developer-suite используйте:

```bat
scripts\run_tests.bat
```

Скрипт создаёт отдельное `.runtime\dev-venv` и использует `requirements-dev.lock`.

В веб-интерфейсе кнопки «Быстрый тест» и «Полная диагностика» запускают только встроенную диагностику приложения.

## Диагностика запущенного экземпляра

```bat
scripts\diagnose.bat
```

Скрипт читает фактический порт из `data\runtime.json`, проверяет PID/TCP и открывает раздел тестов только для живого экземпляра.

## Source of truth

Этот репозиторий — единственный источник истины проекта. Текущее состояние находится в `PROJECT_STATE.json`, очередь задач — в `TASKS.json`, история — в `CHANGELOG.jsonl` и `ERRORS.jsonl`, архитектурные решения — в `DECISIONS.md`. Текущая версия проекта хранится только в `VERSION`.
## Интерфейс
- **Обзор**: состояние системы, часы и календарь с заметками на день.
- **Настройки**: тема (тёмная, чёрная, белая, как в системе), цвет акцента, фон (свечение, однотонный, своё изображение), масштаб, анимации, формат времени, начало недели, автозапуск, экспорт данных.

## Аватар, чат и личный кабинет
- Аватар доступен на любой странице. Перетаскивается куда угодно; можно загрузить своё лицо, подобрать кадр и применить его везде. Настраиваются форма, размер, прозрачность, рамка, свечение, анимация, прилипание к краю, приглушение, приветствие и действия левого/правого клика.
- **Левый клик** — чат в стиле ChatGPT (Markdown, код с копированием, подсказки, новый чат).
- **Правый клик** (на сенсорном экране — долгое нажатие) — личный кабинет: профиль, аватар, ИИ, память, система. Окна чата и кабинета можно двигать за заголовок и менять размер за любой край или угол.
- **ИИ**: Anthropic (Claude), Cloud.ru (Foundation Models), любой OpenAI-совместимый API, в том числе локальный (Ollama). API-ключ хранится только в `data/secrets.json` и никогда не показывается обратно.
- **Память**: вставьте или загрузите диалоги (экспорт ChatGPT/Claude, JSON, JSONL, текст) и заметки; подходящие фрагменты подставляются в запрос. Это не дообучение модели, а локальная долговременная память.

## Оформление
Мягкий «лисий» стиль: узор «волны» (сэйгайха), светящиеся хвосты на фоне, лепестки сакуры, классические заголовки. Узор, лепестки и анимации отключаются в настройках; темы: тёмная, чёрная, белая, как в системе. В чате есть кнопка «Остановить», разделители по дням и крупный аватар.
