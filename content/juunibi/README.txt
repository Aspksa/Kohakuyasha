JUUNIBI — 365 кинематографичных действий перед разговором

Содержимое:
- JUUNIBI_365_cinematic_actions.json — 365 разных действий и настройки генерации.
- JUUNIBI_action_selector.mjs — готовый выбор без повторов с сохранением истории.
- JUUNIBI_452_phrases.json — отдельные ранее созданные реплики.
- JUUNIBI_character_v1.json — характер персонажа.

Как работает:
1) Перед репликой приложение вызывает await selector.next().
2) Показывает действие и анимацию.
3) Произносит выбранную реплику из отдельной библиотеки фраз.
4) История использованных действий сохраняется в доступном persistent storage.
5) После 365 использований приложение запрашивает новое действие через callback generate.
6) Новое действие валидируется, добавляется в сохраняемый набор, затем воспроизводится.
7) Если AI provider недоступен, повтор НЕ происходит, будет ошибка.

Для Cloud.ru подключить серверный эндпоинт /api/juunibi/generate-action с моделью
DeepSeek-V4-Flash. Не хранить ключ в браузере. До подключения API автогенерация не работает.

Важно:
Это библиотека действий и система выбора, а не дообучение весов нейросети.
Память действий реализована через persistent storage. При очистке localStorage
история пропадёт; для долговременной и синхронизированной памяти используйте SQLite.
Внешняя интеграция с репозиторием не выполнялась.
